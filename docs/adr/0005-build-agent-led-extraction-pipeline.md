# Build an agent-led extraction pipeline

The full solution needs an **Agent-Led Extraction Pipeline**, not just checked-in GeoJSON outputs. Public ATM map graphics and documents require repeatable extraction, source linking, confidence scoring, caveating, validation, and manifest publication so future agents can extend B&NES coverage without hiding judgement in ad hoc manual geometry edits. The pipeline should use **Agent-Proposed Georeferencing** and reserve human effort for exception review and sign-off.
