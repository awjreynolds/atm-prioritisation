# Start with a B&NES-wide full product pass

The next full-solution direction is a **B&NES-Wide Full Product Pass**: ATM Source Layer extraction, Evidence-Backed Corridors, destinations, route roles, modal-shift judgement, independent-travel lens, and broad intervention need across the authority area. This rejects a pilot-only tracer and a source-only coverage pass because the product needs to demonstrate the full decision-support experience B&NES-wide, while still using confidence flags, caveats, and review-safe defaults to avoid overstating certainty.
